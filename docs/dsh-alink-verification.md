# Alink 0.2.0 验证记录

2026-11-04，macOS Apple Silicon，官方未修改的 DSH 0.2.1-rc.5，Node 24.14.0。

34 项单元测试、21 项原生服务集成测试和 11 项浏览器检查通过。

## 功能验收

- 原生 DSH 历史只写入用户/助手对话和可用的用户附件；工具调用、执行输出、推理和自动规则/环境说明不进入目标会话或续聊请求。
- 按项目、多来源多选后直接导入；可选查看对话，不要求先生成预览。
- 导入前即可独立导出单条或多条会话，集合 ZIP 可从本地重新批量导入。
- 排队中的来源被归档时阻止该项，其他有效项继续；失败重试不重写已完成项。
- Host 重启后可恢复未完成任务，覆盖原生写入已完成但批次条目凭据未保存的中断窗口。
- 删除迁移记录保留 DSH 会话及重复保护；进行中的记录不能删除。
- 旧映射预览无法继续提交工具历史，旧完成记录可重新导入为独立的纯对话会话。
- 批量完成后刷新原生会话列表和标题；布局覆盖 1440、900、600 像素、长标题、长路径、长正文、复选框和下拉框。

本地发布包和 GitHub `v0.2.0` 固定标签均通过完整流程。验收使用合成来源、真实 DSH 运行时及本地测试模型，覆盖四个外部来源和旧 DSH v0 文件。5 条目标会话分别通过重启续聊和卸载插件后续聊，共 10 次本地模型请求。

## 本机来源只读检查

对当前可读取的 15 条 Codex、5 条小浣熊有效会话做了只读捕获与计划检查，20 条均能生成含对话的迁入计划，没有完整性阻断。未将这些真实会话自动写入 DSH，也未调用模型。

Codex 分页历史按引用截止位置恢复旧日志；两条旧日志已不可用的会话通过原应用历史索引恢复对话。回归测试同时确认：截止点之后的记录、后续更新的消息及工具记录不会被带入继承历史。

## 复现

```sh
pnpm typecheck
pnpm test
pnpm test:integration
pnpm test:e2e
```

完整验收需要 Google Chrome。测试使用隔离的 DSH_HOME；`DSH_ALINK_TEST_CLI` 可指定另一个 DSH JavaScript 启动文件。结果保存在 `.local/releases/latest-smoke.json`，测试日志位于 `.local/verification`。

[GitHub 安装与验收](github-installation.md)记录发布标签的验证结果。原始包格式见[归档说明](format-v0.1.md)。

## 0.2.1 交互更新

项目列表与右侧选择面板采用圆角分组、蓝色勾选及轻量控件，验证浅色、深色和窄窗口。选中会话后自动读取文本，不依赖目标目录或 DSH 配置；读取期间显示动态图标，切换会话会取消旧请求，延迟返回的旧内容不能覆盖新选择。读取缓存不能提交为迁移操作，也不保留临时原始快照。

成功提示改为 4 秒自动消失的浮层，历史成功任务不再固定占用顶部。导出先请求系统保存位置，确认后才创建任务，生成的字节直接写入所选文件。取消选择不创建导出；服务端校验失败不会打开已有文件进行写入；写入失败不会报告保存成功。自动化测试使用受控文件选择器验证调用顺序与写入字节，导出 ZIP 随后通过真实导入校验。

0.2.1 已通过 38 项单元、22 项集成和 12 项浏览器检查，以及 GitHub 固定标签的全新安装与两轮续聊。浅色、深色和窄窗口的选择控件已检查。桌面端原生保存对话框尚未完成实测：本机窗口控制返回无可用窗口/元素无位置，未据此宣称桌面文件保存已通过。

## 0.2.2 多会话展示

多选时按选择顺序渲染每条会话，不再共享单个焦点预览。各卡片拥有自己的加载动画、消息列表、折叠状态、分页和错误重试；未选择的会话响应不会重新加入界面。自动读取并发限制为 2，避免全选时同时启动大量来源读取。

只读显示缓存从三条内存记录改为最多 100 条本地临时缓存，关闭和重启清理，不产生迁入计划或操作记录。集成验证五条会话读取后均能继续翻页；浏览器验证四条同时展示、取消一条不影响其他分页、单条失败与重试、旧响应隔离，以及已有浅色/深色/窄窗口布局。

本地 0.2.2 发布包及 GitHub `v0.2.2` 全新安装验收通过：38 项单元、23 项集成、13 项浏览器检查，5 条迁入会话分别通过重启和卸载插件后的续聊。测试仅使用合成数据与本地模型。桌面端窗口控制仍不可操作，未把浏览器保存选择器替身的结果当成原生系统保存弹窗验收。
