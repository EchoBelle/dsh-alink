# dsh-alink

**Alink** 是 DeepSeek Harness 的原生 TypeScript 插件，将当前有效、未归档的 WorkBuddy、Codex、小浣熊和 Cursor 会话迁入 DSH，并继续对话。

## 安装

当前适配 **DSH 0.2.1-rc.5**、Node.js **24.14+（24 系列）**，已在 macOS Apple Silicon 验收。仓库包含预构建文件，普通用户无需 pnpm 或源码编译。

```sh
npm install -g @deepseek-ai/dsh@0.2.1-rc.5
dsh plugin --profile web add --workspace-root github:EchoBelle/dsh-alink#v0.2.0
dsh web
```

已有匹配版本 DSH 时跳过第一行。安装绑定到所选 profile；首次使用可先执行 `dsh --profile web --dump-config`。

## 使用

1. 在 DSH 侧栏打开 **Alink**，选择来源应用，按项目浏览会话。
2. 勾选单条、多条或整个项目；切换来源应用时保留已选项，每批最多 100 条。
3. 选择保留各会话的原项目，或统一导入到指定目录，然后点击 **导入所选**。无需先生成预览；“查看对话”是可选操作。
4. 任务在 DSH Host 中排队执行，逐条显示结果。关闭 Alink 面板不影响任务；失败项可重试，已完成项不重复写入。Host 停止后，未完成项会保留为可重试状态。

**导出所选** 可以独立使用，不要求先导入 DSH。单条导出为 ALink 会话 ZIP，多条打包为一个 Alink 集合 ZIP。通过 **从本地导入** 可选择多个文件或读取整个集合，再批量导入。

**迁移记录** 提供打开会话、查看对话、重试和删除记录。删除记录只清除列表中的条目，保留来源会话、已迁入的 DSH 会话以及防止重复导入所需的内部凭据。

## 迁入内容

| 内容 | 处理 |
|---|---|
| 用户问题、助手答复 | 写入原生 DSH 对话，保持角色、正文及顺序 |
| 用户消息中可用的文件和图片 | 通过 DSH 附件服务关联到用户消息 |
| 工具调用、参数、执行输出、推理、运行状态 | 只保存在导出包，不写入 DSH 对话 |
| 自动注入的规则和环境说明 | 不写入 DSH 对话；原记录保留在导出包 |
| 隐藏或失效消息、独立生成的产物 | 保留原记录，不恢复为活动对话 |

Codex 分页会话会按引用的截止位置补齐历史日志；旧日志已不可用时，尝试读取原应用的历史索引。上下文压缩本身不再阻止对话迁入。确实找不到的早期记录不会伪造：迁入可读取的对话，并在任务结果中提示。没有可读取对话或无法确定有效分支的来源仍会报告具体问题。

0.2.0 使用新的迁入规则。旧版已经写入 DSH 的工具记录不会被当作新版结果复用；可在旧迁移记录中点击 **重新导入纯对话**，创建干净副本并保留已有会话及续聊。

迁移本身不调用模型。继续对话由 DSH 当前模型、工具和权限设置处理；DSH 的轮次与流式展示由导入内容重建。

## 有效性与备份

归档校验覆盖列表、捕获前后、备份注册、排队执行、写入前及重试。排队期间被归档的会话会被拦截，其他有效项继续处理。备份必须关联到原应用中仍可核实为有效的会话，不能用旧备份绕过校验。

本地导入支持 ALink 0.1 会话 ZIP/目录、Alink 集合 ZIP，以及旧 DSH v0 JSONL/Zstandard 文件。当前 DSH 输出的会话不作为自动扫描来源。

原始会话格式仍为 `alink.session` 0.1.0；批量包使用 `alink.collection` 0.1.0，包含各条会话的独立归档。原始记录可包含工具详情，但重新迁入时仍只写入对话内容。

## 数据与边界

默认数据目录为 `$DSH_HOME/storages/dsh-alink`，保存快照、原始记录、资源、任务状态及操作凭据。来源数据只读；资源仅在来源根目录或显式允许的目录内收集，不自动抓取远程 URL。

配置项包括 `dataDir`、`sourceRoots`、`resourceRoots`、`maxTextBytes` 和 `maxMessages`。来源键为 `workbuddy`、`codex`、`raccoon`、`cursor`、`dsh`，空字符串禁用该来源。扫描发生在 DSH Host 所在电脑；默认路径以 macOS 为基础，其他系统需配置对应来源目录。

默认限制：单条 JSONL 16 MiB，归档及解压内容 2 GiB、ZIP 100000 条目，单会话对话文本 32 MiB、50000 条消息。超过限制会明确失败，不静默截断迁入内容。图片另受 DSH 附件限制。

重试使用持久化的预览和目标会话标识。中断后只补写匹配的历史前缀，不覆盖已经改变的目标会话。删除迁移记录后再次导入相同快照，仍会复用原结果。

## 开发与验证

```sh
pnpm install
pnpm check:dsh
pnpm typecheck
pnpm test
pnpm test:integration
pnpm test:e2e
```

`test:e2e` 自动构建发布包，在隔离 DSH profile 中验证批量导出和导入、原生对话内容、记录删除、归档拦截、重启续聊和卸载插件后的续聊，需要 Google Chrome。测试仅使用合成来源及本地测试模型。
